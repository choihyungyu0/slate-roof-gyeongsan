# 과거 항공사진 변화탐지 — 가능성 조사와 설계

2026-10-05 조사. **자료는 아직 받지 않았다**(다운로드는 사용자가 직접).

## 1. 받을 수 있는가

| 항목 | 확인한 내용 | 출처 |
|---|---|---|
| 제공처 | 국토지리정보원 국토정보플랫폼 (map.ngii.go.kr) | 공공데이터포털 「국토지리정보원_정사영상」 |
| 연도 | 정사영상은 **2010년 이후** 촬영분 제공. 2021년부터는 매년 촬영 | 같음 |
| 해상도 | 도심지역 12cm, 일반지역 25cm | 같음 |
| 형식 | TIFF | 같음 |
| 비용·이용범위 | 무료, 이용허락범위 제한 없음으로 기재 | 같음 |
| 로그인 | 다운로드 시 로그인 필요. 대용량 파일전송 프로그램이 자동 설치됨 | 같음 |
| 경로 | 포털 접속 → 통합검색(지명 입력, 예: 경산시 자인면) → 검색결과 선택 → 우측 검색마커 선택 → 정사영상 선택 → 연도 선택 | 같음 |

**확인하지 못한 것**
- **자인면 일대에 2010~2016년 중 어느 연도 영상이 실제로 있는지**: 미확인. 국토정보플랫폼이 자동 접속을 차단해("Request Blocked") 목록 화면을 직접 보지 못했다.
- **파일 크기**: 공식 설명에 기재 없음. 정사영상은 보통 1:5,000 도엽 단위로 제공되는데, 그 크기(약 2.2km × 2.8km)를 25cm 해상도 3밴드 비압축으로 계산하면 도엽당 약 300MB다. 이는 계산에 의한 추정이며 실제 파일 크기는 다운로드 화면에서 확인해야 한다.
- 자인면 전체를 덮는 도엽 수: 미확인(면적상 여러 장).
- 신청 후 승인 절차가 있는지: 공식 설명에는 없고, 일부 안내 글에는 항공사진(원본)은 신청·승인 후 마이페이지에서 받는다고 되어 있다. 정사영상도 같은지 미확인.
- 좌표계와 지오레퍼런싱 방식(GeoTIFF 내장인지 별도 좌표 파일인지): 미확인.

**사용자가 확인해 줄 것**: 로그인 후 자인면 소재지(자인면 서부리·북사리 일대)를 검색해 ① 2010~2016년 중 있는 연도 ② 도엽 번호와 파일 크기 ③ 승인 대기 여부. 한 도엽만 먼저 받아도 설계 검증은 가능하다.

## 2. 받으면 할 일

**목표**: 대장에 슬레이트로 적힌 건물 중 "과거와 현재의 지붕 모습이 크게 달라진 건물"을 찾아 **지붕 교체(대장 미갱신) 후보**로 표시한다. 정답 라벨이 필요 없는 비교다.

1. **정합**: 과거 정사영상을 EPSG:5186으로 읽고, 현재 영상(브이월드 줌 19, 약 0.24m)과 같은 격자로 맞춘다. 건물 도형(GIS건물통합정보)은 현재 기준이라 과거 영상과 어긋날 수 있으므로 도형을 안쪽으로 1m 줄여 지붕 안쪽만 쓴다.
2. **건물별 지표** (도형 안 화소만 사용)
   - 색 차이: 과거·현재 평균색의 Lab 색차(ΔE). 회색 → 유채색(청·적·녹) 변화가 강판 교체의 전형이므로 채도 변화량을 따로 본다.
   - 질감 차이: 밝기 표준편차·기울기 크기 평균의 변화. 얼룩진 풍화면 → 균일한 면.
   - 건물 유무: 과거에는 지붕, 현재는 지면·식생(녹색 비율)으로 보이면 "건물 없음 후보".
3. **촬영 조건 보정**: 두 영상의 계절·시각·색보정이 달라 전체적으로 색이 다르다. 대장이 콘크리트 슬래브인 건물 등 "바뀌지 않았을 건물"의 변화량 분포를 기준선으로 삼아, 그보다 뚜렷이 큰 건물만 후보로 올린다.
4. **산출**: 대장=슬레이트(슬레이트 단독·혼합) 건물을 변화량 순으로 정렬한 목록과 과거·현재 나란히 놓은 이미지. 상위 건물 = 지붕 교체 후보, 건물 유무 변화 = 철거 후보.
5. **화면 연결**: 3D 지도 패널에 "과거·현재 영상"과 변화량 등급을 붙인다.

## 3. 미리 알 수 있는 한계

- 변화량이 크다는 것은 "모습이 달라졌다"이지 "슬레이트를 철거했다"가 아니다. 슬레이트 위에 강판을 덧씌운 경우도 똑같이 잡힌다(석면은 그대로 남음).
- 반대로 슬레이트를 같은 회색 계열 재료로 바꿨으면 잡히지 않는다.
- 그림자·나무·촬영 각도 차이로 거짓 변화가 생긴다. 과거 영상이 2010년 이후뿐이라 그 전에 바꾼 지붕은 "변화 없음"으로 나온다.
- 후보의 실제 적중률은 현장 확인이나 철거 지원 실적 같은 기록이 있어야 알 수 있다.
