# 2차 독립 판독 교차검증 (2026-10-27)

- 대상: 건물 도형과 연결된 건물의 지붕 자유기재 고유 표기 2,378종 (etc_rc.json: 표기별 사이트 판정 분포)
- 방법: 규칙표를 보여 주지 않은 독립 판독(LLM 3개 묶음, chunk0~2)이 각 표기를 S(슬레이트)/M(혼합)/N(비슬레이트)/U(판정 보류)로 분류 → label0~2.json
- 비교: compare.py (사이트 판정은 표기별 최다 분류)
- 결과: 양쪽 모두 판정한 2,184종 중 2,183종이 슬레이트 포함 여부 일치(99.95%)
  - 불일치 1종: 천연슬레이트잇기 (천연석, 석면 아님) → 규칙표 개정 대상
  - 한쪽만 판정 보류 101종(건물 523동) → 사람 검토표(온지붕_교차검증_불일치_검토표.csv)
- 한계: 같은 계열 모델이라 완전 독립은 아님. 표기 해석의 일치이며 실제 지붕 정확도는 현장 확인으로만 알 수 있음
