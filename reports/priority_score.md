# 우선순위 점수 설계 (안)

2026-10-05. 노후도·면적·기재 확실성 3개 항목은 계산했다(`priority_result.md`, `src/priority_score.py`). **학교·어린이집·경로당 거리는 위치 자료를 받지 못해 미반영.** 공공데이터포털 표준데이터(학교 15021148, 어린이집 15013108, 마을회관·경로당 15114136)는 API가 현재 키로 등록돼 있지 않고(SERVICE_KEY_IS_NOT_REGISTERED), 파일 내려받기는 자동등록 방지 절차가 있어 받지 않았다. CSV 3개를 `data/raw/poi/` 에 넣으면 같은 스크립트가 거리 항목까지 계산한다.

## 성격

정답이 있는 예측 점수가 아니라, "한정된 지원 물량(2026년 주택 철거 95동, 아주경제 2026.4.11 보도)으로 어느 집부터 찾아갈 것인가"를 정하는 **정책 점수**다. 그래서 정확도를 말하지 않고, 항목·가중치·근거를 전부 공개해 담당자가 바꿀 수 있게 한다.

대상은 대장 지붕 기재 정규화에서 슬레이트·혼합·코드만 슬레이트로 분류된 주택 6,092동(`reports/roof_normalization.md`).

## 점수에 넣지 않고 표시만 하는 것

| 표시 | 이유 |
|---|---|
| 영상 참고 점수 | 연식 착시가 확인돼(`reports/exp_post2010.md`) 점수에 넣으면 노후도를 두 번 세는 셈이 됨 |
| 대장-도형 불일치(1,134동) | 건물 위치를 특정할 수 없어 거리 항목을 계산할 수 없음. 별도 목록으로 관리 |
| 과거·현재 영상 변화량 | 자료 확보 전(`reports/change_detection.md`). 확보되면 "이미 바뀐 것으로 보임" 표시로 순위를 낮추는 데 쓸 수 있음 |

## 넣고 싶지만 자료가 없는 것

- 거주 여부(빈집), 거주자 연령·소득: 개인정보이거나 건물 단위 공개 자료가 없음. 다루지 않는다.
- 과거 철거 지원 이력: 경산시 내부 자료. 정보공개청구 대상.
- 지붕 파손 정도: 현장 확인으로만 알 수 있음.

## 검증 방법 (정답 없이 할 수 있는 것)

- **민감도**: 가중치를 항목별로 ±0.1 바꿨을 때 상위 95동이 얼마나 바뀌는지(겹치는 비율)를 보여준다. 많이 바뀌는 항목은 화면에서 담당자가 직접 조정하게 한다.
- **쏠림 점검**: 상위 95동이 특정 읍·면이나 특정 연대에 몰리는지 표로 확인한다.
- **사후 비교**: 현장 확인 기록이 쌓이면 점수 상위 집단의 "슬레이트 맞음" 비율을 하위 집단과 비교한다(`reports/design.md`의 순환 구조).

## 남은 결정

1. 경로당 위치 자료를 어디서 받을지(없으면 이 항목을 빼고 가중치를 재배분).
2. 거리 기준을 직선거리로 둘지, 통학로 등 실제 경로로 볼지(직선거리가 기본).
3. 가중치 기본값을 경산시 담당 부서 의견으로 조정할지.
